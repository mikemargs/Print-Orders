# Store Setup Checklist

Complete this checklist separately for Sayville, Selden, and Mt. Sinai.

## Before installation

- [ ] Central server health page works from the store's internet connection
- [ ] Administrator knows the company code and password
- [ ] Store location and number are correct
- [ ] Current local database has a verified backup
- [ ] Employee list, roles, and store assignments are approved

## Installation

- [ ] Install `PrintOrderManager-MultiStore-Setup.exe`
- [ ] Enter the HTTPS server address
- [ ] Enter company credentials
- [ ] Select the correct store
- [ ] Sign in as Administrator
- [ ] Create employee profiles and unique PINs
- [ ] Create one test customer and test work order
- [ ] Confirm the test order appears from another store/client
- [ ] Preview and print the job ticket

## Offline test

- [ ] Disconnect the test computer from the network
- [ ] Confirm the yellow offline banner appears
- [ ] Create a clearly labeled test order
- [ ] Confirm the pending-change count increases
- [ ] Reconnect the network
- [ ] Confirm the pending count returns to zero
- [ ] Confirm the test order appears on another client

## Migration sign-off

- [ ] Import legacy customers and orders, if applicable
- [ ] Compare customer count
- [ ] Compare active-order count
- [ ] Spot-check at least five order totals
- [ ] Check overdue and ready-for-pickup orders
- [ ] Confirm each order is assigned to the correct store
- [ ] Record the migration date
- [ ] Retain the old database backup according to company policy
