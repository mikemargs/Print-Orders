# React PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full online React/TypeScript client for multi-store print-order operations.

**Architecture:** Vite React SPA uses only FastAPI REST/session APIs. TanStack Query owns server state, React Hook Form/Zod own forms, and Uppy/TUS handles direct storage uploads.

**Tech Stack:** React, TypeScript, Vite, React Router, TanStack Query, React Hook Form, Zod, Vitest, Testing Library, Uppy/TUS.

**Spec:** `docs/superpowers/specs/2026-10-02-print-order-manager-web-and-hardening-design.md`

## Global Constraints

- Desktop/tablet/phone layouts supported.
- No bearer JWT in browser storage.
- Mutations send CSRF token.
- 409 conflicts require explicit resolution.
- No browser offline writes in this plan.

## Review Focus

- Session expiry during a dirty form must preserve user-entered data where practical.
- 409 conflicts must show current-server state.
- Empty states must be intentional and clear.
- Upload retry/error must not destroy order form state.
- Phone-width editing must retain all required actions/fields.
